## インストール

### ローカルから

```bash
picoclaw skills install https://github.com/yagi-agent/picoclaw-yagi
```

### URLから

```bash
picoclaw skills install https://raw.githubusercontent.com/yagi-agent/picoclaw-yagi/main/skill.json
```

## ファイル構成

- `SKILL.md` - やぎちゃんの性格定義とIDENTITY情報
- `skill.json` - スキルのメタデータ
- `README.md` - このファイル
